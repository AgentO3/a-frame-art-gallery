# Gallery material sources

- `plaster.webp`, `plaster-normal.webp`: **Plaster Grey 04**, Poly Haven. https://polyhaven.com/a/plaster_grey_04
- `marble.webp`, `marble-roughness.webp`: **Marble 011**, ambientCG. https://ambientcg.com/a/Marble011

Both source assets are released under CC0 1.0 Universal (public domain dedication): https://creativecommons.org/publicdomain/zero/1.0/

The color maps are optimized 1K WebP derivatives; the normal and roughness maps are optimized 512px derivatives. Lighting, sky/cloud texture, contact shadows, and gallery geometry are generated by this application. No external network requests are needed at runtime.
